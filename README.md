# Toshkent uy qidiruvi

Toshkentdagi ijara va sotuv e'lonlarini (kvartira va hovli) bitta sahifada filtrlash uchun shaxsiy, oilaviy foydalanishdagi sayt.

Sayt: https://behzodutkirov01.github.io/uy-qidiruv/

`data/` papkasidagi fayllar kuniga bir marta avtomatik yangilanadi. E'lonlarning asl manbasi OLX.uz, Birbir.uz va Joymee.uz; har bir e'lon o'z saytidagi sahifaga olib boradi.
